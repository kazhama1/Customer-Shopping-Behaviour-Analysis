# Customer Shopping Behaviour Analysis

## Introduction

This project analyses customer shopping behaviour
using Python and data mining techniques.

The project focuses on understanding purchasing
patterns, customer spending habits and product
relationships.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Mlxtend

## Algorithms Used

### 1. K-Means Clustering
Used to segment customers based on their
Recency, Frequency and Monetary (RFM) values.

### 2. Apriori Algorithm
Used for Market Basket Analysis to discover
frequently purchased products and association rules.

## Project Features

- Data preprocessing
- Exploratory Data Analysis
- Customer spending analysis
- Product popularity analysis
- Monthly sales analysis
- Customer segmentation
- Market Basket Analysis
- Association rule generation

## Dataset

Online Retail Dataset (Online Retail.xlsx).

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the Python program:

python main.py

Make sure Online Retail.xlsx is in the
same folder as main.py.
